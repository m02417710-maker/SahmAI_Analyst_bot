## 📊 شرح المميزات الرئيسية

### 1. تحليل الأسهم

#### المؤشرات المعروضة:
- **السعر الحالي**: السعر الأخير للسهم
- **RSI**: مؤشر القوة النسبية (0-100)
  - < 30: ذروة بيع (فرصة شراء)
  - > 70: ذروة شراء (فرصة بيع)
  - 30-70: منطقة محايدة

- **SMA 20 و 50**: المتوسطات المتحركة
  - إذا كان السعر فوقهما: اتجاه صاعد
  - إذا كان السعر تحتهما: اتجاه هابط

- **Volume Ratio**: نسبة حجم التداول
  - > 1.5x: حجم قوي (ثقة في الاتجاه)
  - < 0.5x: حجم ضعيف (تحفظ)

#### الرسم البياني المتقدم:
يعرض 4 طبقات:
1. **السعر مع المتوسطات**: OHLC + SMA + Bollinger Bands
2. **RSI و Stochastic**: مؤشرات الزخم
3. **MACD**: مؤشر الاتجاه
4. **حجم التداول**: تأكيد الاتجاه

#### الإشارات:
- 🟢 **شراء**: عندما تتوافق معظم المؤشرات على صعود
- 🔴 **بيع**: عندما تتوافق معظم المؤشرات على هبوط
- 🟡 **انتظار**: عندما تكون المؤشرات مختلطة

### 2. الصناديق الاستثمارية

#### أنواع الصناديق المعروضة:

**صناديق الأسهم**:
- عائد أعلى، مخاطر أعلى
- مناسبة للمدى الطويل
- متوسط الأداء: 12-18% سنوياً

**صناديق الدخل الثابت**:
- عائد منخفض، مخاطر منخفضة
- مناسبة للأمان
- متوسط الأداء: 7-8% سنوياً

**صناديق متوازنة**:
- توازن بين الأسهم والسندات
- مناسبة للمتوسط
- متوسط الأداء: 9-10% سنوياً

**صناديق عالمية**:
- تنويع عالمي
- رسوم منخفضة جداً
- عوائد محترمة بأمان أعلى

### 3. معلومات البورصة المصرية

## 📈 كيفية استخدام المؤشرات الفنية

### 1. RSI (Relative Strength Index)

**الاستخدام**:
- < 30: ذروة بيع (احتمالية صعود)
- 30-50: ضعف نسبي
- 50-70: قوة نسبية
- > 70: ذروة شراء (احتمالية هبوط)

**الإستراتيجية**:
```
شراء: عندما RSI < 30 والسعر أعلى SMA50
بيع: عندما RSI > 70 والسعر أقل SMA50
```

### 2. MACD (Moving Average Convergence Divergence)

**الاستخدام**:
- عندما MACD > Signal Line: إشارة صعود
- عندما MACD < Signal Line: إشارة هبوط
- كلما زاد الفرق: قوة الاتجاه أكبر

**الإستراتيجية**:
```
شراء: MACD يقطع Signal Line من الأسفل
بيع: MACD يقطع Signal Line من الأعلى
```

### 3. Bollinger Bands

**الاستخدام**:
- السعر قريب من العلوي: قوة (أو ارتفاع زائد)
- السعر قريب من السفلي: ضعف (أو انخفاض زائد)
- عرض الفرقة يدل على التقلب

**الإستراتيجية**:
```
شراء: السعر يلمس Band السفلي
بيع: السعر يلمس Band العلوي
```

### 4. حجم التداول

**الاستخدام**:
- Volume High: تأكيد الاتجاه
- Volume Low: ضعف الاتجاه
- Volume Spike: اهتمام كبير

**الإستراتيجية**:
```
شراء: صعود مع حجم عالي
بيع: هبوط مع حجم عالي
تجاهل: تحرك بحجم منخفض
```

## 💡 نصائح الاستثمار الناجح

### 1. إدارة المخاطر (Risk Management)

```
حجم المركز = (رأس المال × نسبة المخاطرة) / نقاط الخسارة

مثال:
- رأس مال: 100,000 جنيه
- نسبة المخاطرة: 2% (2,000 جنيه)
- Stop Loss: 100 نقطة
- حجم المركز: 20 سهم
```

### 2. تحديد الأهداف

```
Entry Point: السعر الذي تدخل فيه
Stop Loss: السعر الذي تخرج عند الخسارة
Take Profit: السعر الذي تأخذ عنده الربح

مثال:
- شراء عند: 100
- Stop Loss عند: 95 (خسارة 5%)
- Target 1: 105 (ربح 5%)
- Target 2: 110 (ربح 10%)
```

### 3. عدم وضع كل البيض في سلة واحدة

```
توزيع محفظة 100,000 جنيه:
- 30,000 أسهم عالية الأداء
- 25,000 أسهم مستقرة
- 20,000 صندوق استثمار
- 15,000 دخل ثابت (سندات)
- 10,000 نقد أو نقدية معادلة (للطوارئ)
```

### 4. الصبر والانضباط

```
✓ استثمر على المدى الطويل (5+ سنوات)
✓ لا تتابع الأسعار يومياً
✓ تجنب الشراء والبيع المتكرر
✓ التزم بخطتك الاستثمارية
✗ لا تستثمر برأس مال لا تستطيع خسارته
✗ لا تستخدم أموال مقترضة
✗ لا تقرر بناءً على العواطف
```
