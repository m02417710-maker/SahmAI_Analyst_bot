# 📈 البورصجي AI 2.0 - منصة تحليل الأسهم والصناديق الاستثمارية الذكية

## 🎯 نظرة عامة

### الإصدار: 2.0 - النسخة المحسّنة الشاملة

- ✅ استراتيجيات استثمارية مثبتة

## 🎮 كيفية الاستخدام

### الطريقة 1: تحليل أسهم محددة
```
1. اختر السهم من القائمة
2. حدد الفترة الزمنية (شهر، 3 أشهر، سنة، إلخ)
3. اعرض المؤشرات والإشارات
4. استخدم التحليل الذكي
```

### الطريقة 2: المقارنة بين الصناديق
```
1. اذهب إلى قسم الصناديق الاستثمارية
2. اختر نوع الصندوق
3. قارن الرسوم والأداء
4. اقرأ الوصف والمزايا
```

### الطريقة 3: تعلم الاستثمار
```
1. اذهب إلى معلومات البورصة المصرية
2. تعلم عن المؤشرات والقطاعات
3. اقرأ الاستراتيجيات
4. ابدأ بخطط عملية
```

## 📈 المؤشرات والإشارات

### 🟢 إشارة شراء
```
شروط الشراء:
- RSI < 40 (ضعف شرائي)
- SMA20 > SMA50 (اتجاه صاعد)
- حجم تداول عالي (تأكيد)
- MACD > Signal (قوة شرائية)
```

### 🔴 إشارة بيع
```
شروط البيع:
- RSI > 60 (قوة شرائية)
- SMA20 < SMA50 (اتجاه هابط)
- حجم تداول منخفض (ضعف)
- MACD < Signal (ضعف شرائي)
```

### 🟡 إشارة انتظار
```
عندما:
- المؤشرات مختلطة
- النطاق جانبي
- عدم وضوح الاتجاه
- الحجم منخفض جداً
```

## 💡 نصائح الاستثمار الذهبية

### 1. إدارة المخاطر (Risk Management)
```
✓ لا تخاطر بأكثر من 2% من رأس المال في صفقة
✓ استخدم Stop Loss في كل صفقة
✓ حدد أهداف الربح مسبقاً
✓ نوّع محفظتك
```

### 2. الصبر والانضباط
```
✓ استثمر على المدى الطويل (5+ سنوات)
✓ لا تتابع الأسعار يومياً
✓ التزم بخطتك الاستثمارية
✓ تجنب الشراء والبيع المتكرر
```

### 3. البحث والتحليل
```
✓ ادرس القوائم المالية
✓ قارن النسب المالية
✓ اقرأ آخر الأخبار
✓ استشر محللين معتمدين
```

### 4. التنويع (Diversification)
```
✓ اشترِ من قطاعات مختلفة
✓ امزج بين الأسهم والسندات
✓ استثمر في صناديق متنوعة
✓ لا تركز في سهم واحد
```
